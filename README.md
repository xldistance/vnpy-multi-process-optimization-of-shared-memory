## 🤖 LLM 移植提示词

> 将以下提示词连同两段代码一起发送给大模型（推荐 GPT-5.5 / Claude Sonnet 4.6 及以上级别）：

```
把以上代码的多进程优化共享内存添加到以下代码
```

**操作步骤：**

1. 将本仓库的【多进程共享内存版组合回测代码】粘贴到提示词**上方**
2. 在中间插入上述提示词
3. 将**你自己的组合回测代码**粘贴到提示词**下方**
4. 提交给大模型，由模型完成代码移植

> 💡 **建议使用 GPT-5.5 或 Claude Sonnet 4.6 级别的模型**，代码理解能力和移植成功率更高。
> 由于代码量较大、改动较多，**一次写成功的概率较低**，做好多轮迭代的准备。

## 🧬 遗传算法优化（多进程共享内存版）

本项目同时提供了**遗传算法参数优化**的多进程共享内存实现版本，适用于策略参数寻优场景。

**主要特性：**

- 种群进化过程并行化，显著降低优化耗时
- 适应度计算使用共享内存，避免进程间重复数据拷贝
- 支持自定义适应度函数，可无缝对接组合回测逻辑

移植方式同上，使用相同的 LLM 提示词即可。
